## Potato OS v0.8.0

### 1. Auto-tune per model family

Settings → Model now has an **Auto-tune** button. It reads the selected model's saved chat profile and proposes a quality preset based on the model name:

- **Code models** (`*coder*`): temperature 0.2, top_p 0.95, repetition penalty 1.05, presence penalty 1.0 — deterministic output that avoids loops.
- **Reasoning models** (`*thinking*`, `*-r1*`, `*reasoning*`): temperature 0.6, top_p 0.95.
- **Everyone else**: the current defaults, so the button reports that there is nothing to change.

You see a diff (`temperature: 0.7 → 0.2`, one line per changed key) before anything is written. **Apply** saves the tuned chat settings for that model; **Cancel** leaves the profile untouched. The model selector stays locked while the diff is open, so a tuning cannot land on the wrong model.

Prompts, token limits, vision settings and llama-server launch options are not touched, and the suggestion endpoint does not persist anything by itself.
